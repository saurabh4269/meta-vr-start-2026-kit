Set up your project using Unreal Engine to take the first step toward developing a Meta Horizon OS app.

Before you begin, set up your development environment, including Unreal Engine and the Meta XR Plugin. This page assumes Unreal Engine 5.4.4 from the Oculus-VR fork, which includes the plugin and other Meta-specific fixes and functionality. If you use a different version, the process is similar. For setup instructions, see [Setting up your dev environment](https://developers.meta.com/vr/documentation/unreal/unreal-quick-start-setup-dev-environ/).

The following steps are needed for setting up your project:

For a full reference of Meta XR Plugin settings, see [Meta XR Plugin Settings](https://developers.meta.com/vr/documentation/unreal/unreal-plugin-settings/).

You can have multiple versions of Unreal Engine on your computer at the same time. Select the version to work with on your new project in the Epic Games Launcher when you create your project.

To create your first project in Unreal Engine 5.4.4, do the following:

1. Open the Epic Games Launcher and then open the **Library** tab.
2. Under**Engine Versions**, find the entry for Unreal 5.4.4 and click **Launch**.
3. In the Unreal Project Browser, select**Games** and then **Virtual Reality**.
4. A description of the generic**Virtual Reality** template is shown on the right. Clear the **Starter Content** option to reduce the initial project size and avoid bundling assets that are not needed for VR development.The template description panel lists the included assets and features.
5. At the bottom of the screen, set the**Project Location** and **Project Name**.
6. Click **Create** to create the new project from the VR template.

With your project created, you need to configure it. How you configure your project depends on your team and your project’s needs. Some of the configuration options (such as **Description**) are largely informational and may only affect your project’s metadata. However, other options include packaging, encryption, and so on. Review all options when configuring your project.

To configure a project in Unreal Engine, do the following:

1. Load your project in Unreal Engine.
2. In the Unreal Editor, go to**Edit** and select **Project Settings**.
3. Under**Project** in the left nav, go through the list of configuration and information options for your project, filling out the appropriate information for each one as required by your team and your project’s needs.**Note**: There are multiple sections covering the various options.
4. Restart the Unreal Editor if prompted.
