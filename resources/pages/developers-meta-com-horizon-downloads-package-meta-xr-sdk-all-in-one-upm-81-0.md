Meta XR All-in-One SDK is a wrapper package that depends on the latest version of all Meta XR SDKs, making it easy to get started with VR development.
Documentation

The Meta XR All-in-One SDK, com.meta.xr.sdk.all, bundles several Meta SDKs together, which includes many features that offer advanced rendering, social and community building, and provides capabilities to build immersive experiences in both virtual reality and mixed reality.

Looking for samples? All-in-One itself does not contain samples, but the dependencies it pulls in might - see the [documentation on samples here](https://developers.meta.com/horizon/documentation/unity/unity-package-manager#meta-xr-samples) for more details. Additionally, larger samples previously found in the Oculus Integrations package have been [moved to Github](https://github.com/oculus-samples/Unity-StarterSamples).
