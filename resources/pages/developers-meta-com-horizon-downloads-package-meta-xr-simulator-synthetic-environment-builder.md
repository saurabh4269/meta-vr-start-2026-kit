The Synthetic Environment Builder lets you use your own synthetic environment for mixed reality simulation in the Meta XR Simulator. It is a UPM package that you can import into your Unity project containing a synthetic environment, and turn that project into a Synthetic Environment Server.
What's New

We released the Synthetic Environment Builder, a Unity package that lets you use your own Unity synthetic environments for mixed-reality simulation in the Meta XR Simulator. This release is identical to v59.

For more details, please refer to the documentation.

Known Issues

The package is only functional in non-VR projects. Please do not import it into a VR project.

A harmless error message (about layers) will occur if the user skips the optional section "Displaying Client Positions in the Server Project" in the manual.
