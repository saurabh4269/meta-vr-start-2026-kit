Meta XR Core SDK provides the latest features to create immersive experiences for Meta XR devices.
What’s New

Use Forward Head Pose: Added a new ‘Use Forward Head Pose’ setting on OVRManager (enabled by default), which improves pixel density balance on devices with canted displays like Quest 3 by letting the compositor separate head pose from eye pose. It works well with the OpenXR provider, but is incompatible with the deprecated Oculus XR provider and should be turned off when using it.

Improvements

FOV Simulation for Meta VR Glasses: Added FOV design area guideline to the FOV Simulator for essential content in Unity tools (OVRManager settings and Immersive Debugger)
