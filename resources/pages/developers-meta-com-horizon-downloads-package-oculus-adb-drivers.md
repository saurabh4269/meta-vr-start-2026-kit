ADB Drivers are required when using ADB with Meta Quest devices.
This download contains the drivers required to use ADB with Android-based Oculus devices. Version 2 adds support for MTP mode connections. For more information, review the  [ADB](https://developers.meta.com/vr/documentation/mobilesdk/latest/concepts/mobile-adb/#mobile-android-debug-intro)  documentation.

To install the driver, unzip the package and right-click >  Install  the  `android_winusb.inf`  file on your PC.
