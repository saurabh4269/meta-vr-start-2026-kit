Updated: Oct 30, 2026

Meta Horizon OS, the operating system on Meta VR devices, is built on the Android Open Source Project. You can create a new Android app for Meta VR devices or make an existing mobile app compatible using familiar tools such as Android Studio, Java, Kotlin, and Jetpack. Meta VR devices display 2D apps in resizable windows within a VR environment and map mobile gestures such as tapping and swiping to controllers and hands.

Choose the workflow that matches how you want to build. Each option can stand on its own, and compatible tools can be combined as needed.

- **Android Studio:** Install the [Meta VR Plugin for Android Studio](https://developers.meta.com/vr/documentation/android-apps/meta-vr-android-studio-plugin) to create Horizon OS projects, generate product flavors, manage Meta Spatial Simulator, and find compatibility issues in your code and manifest.
- **Command line and AI tools:**[Meta VR CLI](https://developers.meta.com/vr/documentation/android-apps/ts-ai-tooling-mcp) comes bundled with the [Meta VR Plugin for Android Studio](https://developers.meta.com/vr/documentation/android-apps/meta-vr-android-studio-plugin). Use it from Android Studio, or install Meta VR CLI independently for use in terminals, continuous integration, and AI coding tools.
- **React Native with Expo:** Follow [Expo for React Native](https://developers.meta.com/vr/documentation/android-apps/expo-for-react-native) tooling and [create an Expo app for Horizon OS](https://developers.meta.com/vr/documentation/android-apps/react-native-apps) to bring an Expo app to Meta VR devices.
- **Replit:** Start from the [Meta VR template on Replit](https://replit.com/partners/meta) to build without setting up Android Studio locally.

Start a new Android project or adapt an existing app for Horizon OS:

- [Create a new app](https://developers.meta.com/vr/documentation/android-apps/create-app) with the required manifest, dependencies, and product flavors for Meta VR devices and mobile.
- [Make your existing app compatible with Meta VR devices](https://developers.meta.com/vr/documentation/android-apps/port-an-existing-app) by addressing unsupported dependencies and permissions while using one codebase across Meta VR devices and other Android platforms.
- [Adapt your UI](https://developers.meta.com/vr/documentation/android-apps/design-requirements) for a mixed reality environment.
- [See what’s new in Meta VR Glasses](https://developers.meta.com/vr/documentation/android-apps/whats-new-in-glasses).
- [Learn about Look and Pinch](https://developers.meta.com/vr/documentation/android-apps/gaze-and-hands).

Follow the [Android design requirements](https://developers.meta.com/vr/documentation/android-apps/design-requirements) when adapting your interface for a device.

For themed Jetpack Compose components that match Meta Horizon OS, use the [Meta VR UI Set SDK](https://developers.meta.com/vr/documentation/android-apps/meta-vr-ui-set-sdk).

Horizon OS offers several ways to enhance your app:

- [User management](https://developers.meta.com/vr/documentation/android-apps/ps-user-management-overview/): accounts and entitlements.
- [User engagement](https://developers.meta.com/vr/documentation/android-apps/ps-user-engagement-overview/): notifications and leaderboards.
- [Monetization](https://developers.meta.com/vr/documentation/android-apps/ps-monetization-overview/): in-app purchases and subscriptions.
- [Security](https://developers.meta.com/vr/documentation/android-apps/ps-security-overview/): attestation and age verification.

Follow the [publish and submit](https://developers.meta.com/vr/resources/publish-submit) guide to get your app into the Meta Horizon Store.

To add revenue streams:

- Explore the [monetization options](https://developers.meta.com/vr/resources/monetization) on Horizon OS.
- Use the [Horizon Billing Compatibility SDK](https://developers.meta.com/vr/documentation/android-apps/horizon-billing-compatibility-sdk/) to reuse familiar Google Play Billing APIs.
- Add advertising with [ad attestation and Ad ID](https://developers.meta.com/vr/documentation/android-apps/ads-attestation).
