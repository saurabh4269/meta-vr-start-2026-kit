Application should be playable in its entirety without the use of audio, or provide subtitle options for in-application dialogue and/or sound effects to communicate progress to the user.

|  | Required ✓ | Recommended + | 
|---|---|---|
| Immersive apps |  | + | 
| Panel (2D) apps |  | + | 

For more information, see the [VR Accessibility Design: Captions and Subtitles](https://developers.meta.com/vr/design/accessibility/).

To test manually:

1. Launch the title.
2. Play through the application content without audio.
3. Enable subtitles in the application.
4. Verify that you see subtitles for dialogue and sound effects.

Application should be playable with no audio or should provide subtitles for all dialogue and sound effects.
