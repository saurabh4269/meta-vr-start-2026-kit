Distribute and grow

Updated: Dec 19, 2024

You can create additional release channels if you need more, or delete them when they are no longer needed.

New release channels are listed at the bottom of existing release channels. When creating or deleting a release channel, consider the following:

- Release channel names are permanent and cannot be changed. You can, however, delete a release channel and create a new one with the name you want.
- When you delete a release channel, all entitlements for that release channel will be deleted as well. For instance, any users with access to that channel will have their access revoked.
- Release channels cannot be reordered. They appear in the list in the order you create them.

1. Go to the [Meta Horizon Developer Dashboard](https://developers.meta.com/vr/manage/).
2. In the left-side navigation, click **My Apps**.
3. Choose the app that you want to create a release channel for from the list of apps.
4. In the left-side navigation, click **Distribution** > **Release Channels**.
5. Click **Create Release Channel** in the upper right, above the list of existing release channels.
6. Fill out the form that opens by providing a **Name**, **Description**, and other information.
7. When finished, click **Submit** to create your new release channel.

1. Go to the [Meta Horizon Developer Dashboard](https://developers.meta.com/vr/manage/).
2. In the left-side navigation, click **Distribution** > **Release Channels**.
3. Find the release channel to delete, and click **(...)** to show the context menu.
4. Choose **Delete Channel**.
