- [Fixed foveated rendering](https://developers.meta.com/vr/documentation/web/webxr-ffr/): Review fixed foveation controls and tradeoffs.
- [Multiview WebGL rendering](https://developers.meta.com/vr/documentation/web/web-multiview/): Review multiview rendering and its WebGL extensions.
- [WebXR frame rate control](https://developers.meta.com/vr/documentation/web/webxr-frames/): Query and change supported WebXR frame rates.

- [Use RenderDoc with Browser](https://developers.meta.com/vr/documentation/web/webxr-perf-renderdoc/): Capture and inspect a rendered frame from Browser.
