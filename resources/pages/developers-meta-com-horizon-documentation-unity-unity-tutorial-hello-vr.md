Follow this Quickstart to configure your development environment, create a Unity VR project, build a hand-tracked UI, and test it.

This section walks you through setting up your development environment and building your first prototype. The guides are designed to be followed in order, and each one picks up where the previous one left off.

| Step | What you do | Frequency | 
|---|---|---|
|  | Verify your development computer, Meta VR device, and USB cable | Once | 
|  | Create accounts, install tools, and configure your Meta VR device | Once | 
|  | Create and configure your Unity VR project | Per prototype | 
|  | Build and configure a hand-tracked UI with buttons, sliders, and toggles | Per prototype | 
|  | Test your prototype using the method that fits your setup | Per prototype | 

You complete Hardware Setup and Software Setup once. After your hardware and software are configured, you don’t need to repeat these stages. If you’ve already completed both stages, skip ahead to [Project Setup](https://developers.meta.com/vr/documentation/unity/unity-project-setup/).

The Quickstart supports three testing methods. [Hardware Setup](https://developers.meta.com/vr/documentation/unity/unity-env-device-setup/) compares their hardware requirements, and [Deploy and Test](https://developers.meta.com/vr/documentation/unity/unity-deploy-and-test/) explains how to use each method. You don’t need to pick one up front because you can switch between them at any time.

| Criterion | Meta XR Simulator | Meta Horizon Link | Build and Run | 
|---|---|---|---|
| **Speed** | Fastest | Fast | Slowest | 
| **Meta VR device** | *Not needed* | Required | Required | 
| **Hand tracking** | Simulated (keyboard/mouse) | Real (streamed) | Real (on device) | 
| **Best for** | Layout, interaction logic | Rapid device testing | Final device validation | 
| **Platform** | Windows, macOS | Windows only | Windows, macOS | 

Start with Meta XR Simulator for rapid iteration, use Meta Horizon Link for real hand tracking without building an APK, then Build and Run for final device validation.
