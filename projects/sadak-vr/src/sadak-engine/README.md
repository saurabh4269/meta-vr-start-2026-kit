`lib/game/**` is copied verbatim from SADAK (github.com/mittal-parth/sadak,
commit fd2f383, `game_engine/lib/game`): only the files the city, its people
and the errand set pieces need. Do not edit these files; adapt in
`src/world/sadak-city.ts` instead, so a fresh copy can replace them.
